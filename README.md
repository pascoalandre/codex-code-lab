# Codex Code Lab

Crie uma aplicação funcional, Um editor de código+ compilador+ executar de C# com sintaxe da Linguagem, a aplicação deve incluir sistema de usuários, para armazenamento de códigos (projetos) com opção de alterar para modo claro e escuro, tema Vs Code , Drácula um aplicativo bem funcional no editor deve ter a opção "Ecrã inteiro" para melhor visualização do editor, o aplicativo deve compilar vários tipos de programas: saída, e de entrada de dados, sectores e matrizes, casos grande de Matemática, e tudo que um bom APP de código deve ter para entrar na concorrência, não deixe o visual do APP bem comum, com de IA bem amador, mais sim com ui/ux profissional como de grande web e APP designer , o APP já deve fornecer alguns códigos já prontos de exemplos, o APP chama-se "C# Codex"
